## 1. Tools and Technologies Used

The application was built using a lightweight, lightning-fast "Vanilla" stack to ensure the app works on any device, even with a poor internet connection.

1. **HTML5**: Used for the structure of the application. It provides semantic elements ensuring the app is accessible to screen readers and easy to navigate.
2. **Vanilla CSS3 (Custom Variables & Glassmorphism)**: Used for styling. The modern "Glassmorphism" aesthetic ensures the app feels premium and visually stunning. Custom variables allow for the seamless toggle between Light and Dark mode, saving battery life for farmers.
3. **Vanilla JavaScript**: The brain of the application. It handles all user interactions, form submissions, and AI predictions instantly without requiring server reloads. 
4. **Chart.js**: An advanced data visualization library used to render beautiful, interactive price forecast charts and seasonal trend graphs. It helps users visually understand price volatility.
5. **Leaflet.js**: Used for maps and live location tracking, crucial for logistics and helping buyers locate farmers easily.
6. **Government Mandi API**: Integrates with live data from `data.gov.in` to ensure that market prices are real-time, accurate, and verified by the Indian government.

**Why this combination?** 
This specific stack ensures the app runs incredibly fast, requires zero downloads, and scales easily on low-end mobile devices—a perfect fit for rural Indian networks.
